# jotly-web

Landing page for **Jotly** — quick expense tracker for iPhone — at [jotly.info](https://jotly.info).

Plain static site; the language pages are generated by one small script (see Languages). Pages: home in 4 languages, `privacy.html`, `terms.html`, `contact.html`.

```
index.html      page markup (sections + app screen mockups)
css/styles.css  design tokens and styles
js/contact.js   contact form (opens the visitor's email app)
js/main.js      interactive quick-jot demo, screen charts
i18n/           page text per language (en, ru, es, hy)
ru/ es/ hy/     generated language pages, do not edit by hand
tools/          build_i18n.py builds the language pages
favicon.ico     browser tab icon (16/32/48)
icons/          tab icons, Apple touch icon, 192/512 icons, og-image.png (link previews)
site.webmanifest
_headers        Netlify response headers (serves sitemap.xml as XML)
robots.txt / sitemap.xml   for search engines (sitemap.xsl makes the sitemap readable in a browser)
```

## Run locally

Open `index.html` in a browser, or serve the folder:

```
npx serve .
# or
python3 -m http.server 8000
```

## Deploy

Any static host works (GitHub Pages, Netlify, Cloudflare Pages). Point the host at the repo root.

## Languages

Each language has its own page so Google can index it separately:

| Language | URL | Text |
|---|---|---|
| English | `/` (`index.html`) | `i18n/en.json` |
| Russian | `/ru/` | `i18n/ru.json` |
| Spanish | `/es/` | `i18n/es.json` |
| Armenian | `/hy/` | `i18n/hy.json` |

`index.html` is the layout template. To change wording, edit the `i18n/*.json` file
(each has its own `meta.title` and `meta.description` for search results). To change
layout, edit `index.html`. Then rebuild the language pages:

```
python3 tools/build_i18n.py
```

The script writes `index.html`, `ru/`, `es/`, `hy/` and `sitemap.xml`, adding the
canonical URL, Open Graph tags and `hreflang` links between the languages.
Don't edit `ru/`, `es/` or `hy/` by hand; they're overwritten on every build.
Privacy, Terms and Contact are English only.
